Small example that shows loading unsupported file types, such as Models, from memory.  
It basically creates a temporary directory, loads the file normally, and deletes it.  
The examples here are just for shaders and models, but this applies to all file types.  

NOTE: Does not work on web because of the shader file being desktop only.
