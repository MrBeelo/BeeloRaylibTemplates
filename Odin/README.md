A couple of notes about the Odin template:  

The odin templates use the version of raylib that's included with  
the compiler (vendor:raylib). As such, it may be outdated, depending  
on the user's odin version.  

In EXTRAS, I've included an example of RayGui, and a style example included  
in a single odin file (rGuiStyler allows exporting to .h files, this is an example  
of how it could be translated into odin). I've also included a resource_dir.odin file,  
as I use it on pretty much every project (from raylibExtras).
