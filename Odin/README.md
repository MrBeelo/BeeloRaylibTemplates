A couple of notes about the Odin template:  

The odin templates use the version of raylib that's included with  
the compiler (vendor:raylib). As such, it may be outdated, depending  
on the user's odin version.  

In EXTRAS, I've included a bunch of small projects using an custom extra feature. They are:  
- OdinFromMemory: Importing models/shaders/textures/sounds from memory.  
- OdinRayGui: Making a style for raygui in Odin.  
- OdinRaylibSelfContained: Making raylib part of the main package (and importing necessary things only).  
- OdinResourceDir: Setting a new default resource location.  
- OdinTextStyled: Drawing styled (colored) text.
